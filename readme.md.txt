
# Kasumi – Sistema de Gestión de Citas

## Descripción
Sistema web de gestión de citas y facturación para spa de uñas.

## Tecnologías
- Backend:Node.js 20 LTS + Express 4
- Base de datos: PostgreSQL 15 + MongoDB 6
- Frontend: React.js 18
- Autenticación: JWT + bcrypt
- Servidor: Nginx + Ubuntu 22.04 LTS

## Módulos
1. Autenticación
2. Dashboard
3. Citas
4. Clientes
5. Especialistas
6. Servicios
7. Reportes
8. Usuarios

## Metodología
SCRUM (6 sprints de 2 semanas)

## Estándares de código
- Variables: camelCase
- Clases: PascalCase
- Métodos: camelCase + verbo
- Comentarios: JSDoc
